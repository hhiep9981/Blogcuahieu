# Blogcuahieu Landing Page

## Description
Company website for **Blogcuahieu**, a Vietnamese software company founded by brothers
Hiep Hoang and Hieu Hoang. Content language: English.

## Products (placeholder names, to be confirmed)
| Name | Domain | Audience |
|------|--------|----------|
| Tide | Bank treasury system (liquidity, FX, money market, limits) | Banks |
| Harbor | Wealth and investment management | Individuals / investors |
| Roots | Family tree / genealogy | Families |

## Stack
- Single static file: `index.html`
- Tailwind CSS v4 browser build (CDN), Geist + Geist Mono (Google Fonts)
- Phosphor Icons (web, CDN)
- Vanilla JS (IntersectionObserver reveal, tabs, mobile menu, copy email)
- Images: picsum.photos placeholders (grayscale + teal tint)

## Design
- Accent: deep teal (`#0d6b67` light / `#3fb3a9` dark), auto light/dark via `prefers-color-scheme`
- Shapes: buttons pill, panels/images 16px radius
- Motion honors `prefers-reduced-motion`
